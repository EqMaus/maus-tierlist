ADMINISTRACIÓN

Edita la tier list sin tocar código

Este editor publica los cambios directamente en EqMaus/maus-tierlist. El token nunca se incluye en la web ni se envía a ningún sitio que no sea la API oficial de GitHub.

Conectar con GitHub

Usa un Fine-grained personal access token limitado únicamente a este repositorio y con permiso Contents: Read and write.

Crear token en GitHub ↗
Cómo crear el token correcto
  1. En GitHub crea un token de acceso específico.
  2. En Repository access, selecciona solo maus-tierlist.
  3. En Repository permissions, pon Contents → Read and write.
  4. No necesitas dar acceso a otros repositorios ni permisos adicionales.
